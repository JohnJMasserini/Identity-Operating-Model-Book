# Errata

Known corrections for *Building the Enterprise Identity Operating Model:
A Framework for Identity Governance, Architecture, and Risk*, organized
by chapter. Each entry links back to the issue where it was discussed, so
you can follow the reasoning behind a correction.

New errata start as issues (see [`CONTRIBUTING.md`](CONTRIBUTING.md)) and
get added to this table once **Confirmed**. Entries marked **Won't fix**
are *not* listed here — they stay closed in the issue tracker with a
reason, so this file only reflects actual corrections.

Table columns:

- **Location** — page number (and edition/printing if it's shifted across
  printings), or a section reference for digital editions.
- **Type** — Typo, Factual, Diagram/Figure, Code/Listing, Reference/Citation.
- **Description** — what's wrong.
- **Correction** — the fix.
- **Status** — Confirmed / Fixed in printing N.
- **Issue** — link to the discussion.

> Page numbers below refer to the Apress uncorrected proof pagination and
> should be re-verified against the final printed/published book before
> this repo goes live — proof pagination commonly shifts by a few pages
> once the final layout is set.
