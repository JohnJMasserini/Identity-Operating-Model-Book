# Building the Enterprise Identity Operating Model — Errata & Updates

This repository is the official errata and updates tracker for *Building the
Enterprise Identity Operating Model: A Framework for Identity Governance,
Architecture, and Risk* by John J. Masserini (Apress).

It exists for two purposes:

1. **Errata** — corrections to mistakes in the published text (typos,
   factual errors, incorrect diagrams, broken references, etc.).
2. **Updates** — post-publication notes on material that has changed since
   the book went to print (new tool versions, revised vendor guidance,
   deprecated practices, and similar drift that isn't a "mistake" so much
   as the field having moved on).

## Reporting an error

If you've found something wrong in the book, please open an issue using
the **Errata Report** template rather than emailing directly — that keeps
a public record other readers can search before reporting a duplicate.

See [`CONTRIBUTING.md`](CONTRIBUTING.md) for what to include in a good
report and how the review process works.

## Status legend

Entries in `ERRATA.md` and in issues use a consistent status vocabulary:

- **Reported** — submitted, not yet triaged.
- **Confirmed** — the author has verified this is an actual error.
- **Fixed in printing** — corrected in a later printing/edition (the
  printing number is noted).
- **Won't fix** — reported but determined not to be an error, or judged
  too minor/ambiguous to correct (with a reason given).
